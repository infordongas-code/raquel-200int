# Bella Glow — Portfólio de produtos de maquiagem

Site demonstrativo desenvolvido com **HTML, CSS e JavaScript**, com arquivos separados para estudar e editar no VS Code.

## Como abrir

1. Baixe e extraia o arquivo ZIP.
2. Abra a pasta `portfolio_maquiagem` no Visual Studio Code.
3. Abra o arquivo `index.html` com a extensão **Live Server** (clique com o botão direito e escolha **Open with Live Server**).
4. O site também pode ser aberto diretamente clicando duas vezes em `index.html`.

## O que o site tem

- Página inicial com apresentação da marca fictícia Bella Glow.
- Catálogo responsivo com produtos de maquiagem.
- Filtros por categoria e busca de produtos.
- Sacola demonstrativa com adicionar, remover e alterar quantidades.
- Formulário de inscrição para novidades com validação básica.
- Menu adaptado para celular.

## Personalização

- `index.html`: estrutura e textos da página.
- `style.css`: cores, layout e responsividade.
- `script.js`: produtos, busca, filtros, sacola e interações.

## Observações

A marca e os produtos são fictícios. Os preços são apenas exemplos e não representam uma loja real. A sacola não processa pagamentos nem envia pedidos. As fotografias são carregadas de URLs externas, então é necessária conexão com a internet para exibi-las.
